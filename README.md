# Anti-AI Paraphraser

Herramienta de escritorio para Windows que parafrasea archivos `.txt` y `.docx` para reducir el plagio y las señales de detección de IA.

## Uso
1. Ve a la pestaña "Actions" en tu repositorio de GitHub.
2. Selecciona el workflow "Build Windows EXE" y espera a que termine.
3. Descarga el artefacto `Anti-AI-Paraphraser-Windows.zip`.
4. Descomprime y ejecuta `AntiAIParaphraser.exe`.

## Créditos
- Motor de reescritura: [TextHumanize](https://github.com/ksanyok/TextHumanize)
- Manejo de DOCX: [python-docx](https://python-docx.readthedocs.io/)
